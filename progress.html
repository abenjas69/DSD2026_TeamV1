Done

  • 2026-05-17 V1 AI Pipeline Design published - Added the first detailed design of the V1 preprocessing and AI pipeline, covering raw JSON ingestion, schema validation, sensor synchronization, feature engineering, target angle alignment, window creation, baseline models, first Deep Learning model planning, post-processing, and future extensions.
  • 2026-05-17 Visual Pipeline Overview added - Published three infographic pages to explain the V1 pipeline faster for other teams, covering data foundations, feature preparation, training inputs, models, outputs, and future extensions.
  • 2026-05-17 First AI task clarified - Defined left_knee angle regression from synchronized IMU data as the first realistic AI task. A complete clinical model remains future work and depends on more sessions, sensor-to-body mapping, exercise context, repetition information, and clinical labels.
  • 2026-04-02 Team website created and published

  • 2026-05-05 Current V2 API format confirmed
  • 2026-05-06 Generation 1 two-angle input and plain-text recommendation scope clarified

Doing

  • Pipeline preparation Pipeline Implementation Preparation - Preparing the implementation of the first pipeline modules: data parser, validation, sensor grouping, timestamp normalization, synchronization/interpolation, wide-format conversion, and training dataset preparation.
  • Data format review S2/V2 payload mapping - Reviewing how sensorData, targetAngles, errors, and sessionId should be converted into model-ready tables and time-series windows.
  • Generation 1 Current API compatibility - Keeping the immediate V1 work compatible with the current V2 Generation 1 API while the richer IMU-based pipeline remains an implementation roadmap.
  • Integration V2 output path review - Reviewing how future pipeline results can be converted into recommendation or analysis outputs that V2 can store and expose to other teams.

To Do / Upcoming

  • First modules Parser and validator - Implement the first code modules for loading pipeline JSON files, validating required fields, reporting invalid sessions, and preserving the original raw data.
  • Preprocessing Synchronized training dataset - Build the first synchronized wide-format dataset with sensor features aligned to the S2-computed left_knee angle.
  • Baseline model First Baseline Model - After the preprocessing pipeline is stable, Team V1 will start with simple baselines for left_knee angle regression before testing a compact Deep Learning model such as a 1D CNN.
  • Future extension Clinical AI requirements - Confirm the extra data needed for a complete clinical model, including more sessions, sensor placement, exercise type, repetition identifiers, and clinical validation labels.
